[The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b)

## The word

> Password123

The whole internet's security in one token: everyone's weakest secret,
guarding everything from bank accounts to cat photos. It makes a reader
laugh, then nod.

## How it works

`main.ts` writes the word to `/output/entry.txt` — one word, 11 characters,
UTF-8, inside the competition's 1–30 character gate.

```sh
node main.ts
cat /output/entry.txt
```
